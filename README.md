# SiteForge

Painel inicial de um construtor de sites, feito com React e Vite.

## O que já funciona
- Painel inicial responsivo.
- Criação de projetos a partir de quatro modelos.
- Busca, renomeação e exclusão de projetos.
- Salvamento local dos projetos no navegador.

## Desenvolvimento
Instale as dependências com `npm install` e inicie com `npm run dev`.

## Observação
Esta é uma versão inicial demonstrativa. Os projetos ficam salvos no navegador usado e ainda não são publicados na internet nem sincronizados entre dispositivos. Editor visual, contas, banco de dados e publicação serão etapas futuras.
